## 常见体育赛事英语表达

| 英文术语                 | 中文意思            | 说明                               |
| ------------------------ | ------------------- | ---------------------------------- |
| **regular season**       | 常规赛              | 正常的赛季阶段，每队按赛程比赛。   |
| **playoffs**             | 季后赛              | 常规赛后的淘汰赛，争夺冠军资格。   |
| **finals**               | 总决赛              | 季后赛最后一轮，决定冠军。         |
| **bracket**              | 对阵图              | 季后赛的排位和进程表。             |
| **knockout stage**       | 淘汰赛阶段          | 输一场就被淘汰的比赛阶段。         |
| **semifinal**            | 半决赛              | 决赛前一轮。                       |
| **quarterfinal**         | 四分之一决赛        | 8 强争夺赛。                       |
| **seed / seeding**       | 种子 / 排名顺序     | 季后赛中根据常规赛成绩安排的排位。 |
| **home court advantage** | 主场优势            | 在自己主场比赛，有更多支持。       |
| **overtime (OT)**        | 加时赛              | 比赛打平后加赛。                   |
| **sudden death**         | 决胜时刻 / 一球定胜 | 一方得分即结束比赛。               |
