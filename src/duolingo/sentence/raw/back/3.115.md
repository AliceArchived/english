### “Would” 的用法之一：表示**过去经常做的事（习惯性行为）**

当我们在回忆过去的某一段时间（特别是童年、夏令营、假期等）经常做的事情时，会用 “**would + 动词原形**” 来描述这种**重复发生的动作**。

例句对比：

- I used to make a new friend every summer.
- I’d make a new friend every summer.
  → 两句话意思几乎一样：过去每年夏天我都会交一个新朋友。

区别在于：

| 用法        | 含义                       | 语气风格         |
| ----------- | -------------------------- | ---------------- |
| used to     | 强调“曾经”如此             | 更中性常见       |
| would / I'd | 更像在**讲故事，有画面感** | 更书面或叙述感强 |

注意：“would” 只能描述动作性的习惯行为（可以**重复**做的事情）
不能用来描述状态类动词（like, know, be 等）
例如：

- ❌ I would be shy as a child.（错）
- ✅ I used to be shy as a child.（对）

### 总结句子用法：

**I’d make a new friend every summer.**
→ 等同于 “I would make a new friend…”
→ 表示“在过去每年夏天我都有这个习惯或经历”

### 小贴士：

- “out east/west” 更常出现在美国口语中，用于指“东部/西部某地”，尤其是纽约人说 “out east” 指长岛
